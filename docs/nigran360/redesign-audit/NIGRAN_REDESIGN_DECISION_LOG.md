# نگران 360: redesign decision log

| # | Decision | Alternatives considered | Reasoning | Trade-off |
|---|---|---|---|---|
| D1 | Keep the existing stack (FastAPI + pyodbc/SQL Server + React/TanStack). No ORM or database migration | Postgres/Alembic (Web-Wizards), an ORM rewrite | Working, tested, deployed-ready architecture; the guarded migration registry already exists; rewriting risks the verified exam guarantees | Raw SQL needs disciplined review (all queries are already parameterized) |
| D2 | Direction **C "Paper & Graphite"** (adaptive), with the navy structural sidebar borrowed from A | A (blended single), B (light only) | Highest weighted score (119/130). Two genuine audiences: readers (candidates) and watchers (invigilators). Both modes share all structure and type | More contrast testing; both modes must ship together |
| D3 | Brand lockup `نگران 360` as an **outlined SVG**, typeset from Gulzar Nastaliq + Source Serif 4 numerals | Live web-font text; Noto Nastaliq; Naskh | Outlines remove shaping and bidi risk in browsers and the PDF; Gulzar is an authentic Urdu Nastaliq that reads well at display sizes; OFL-licensed | The wordmark cannot be edited as text; a separate small-size icon is required |
| D4 | Icon = "open noon" (ن bowl as a 360° ring with the nuqta in the gap) | Shield, eye, graduation cap, abstract hexagon | Derived from the brand's own first letter and the 360 meaning; avoids surveillance and category clichés; legible at 16 px | Needs a short explanation in brand materials |
| D5 | Lapis (`#23408E`) primary, teal secondary, gold for the brand dot only | Keep cyan/violet gradient; green (common in Pakistani branding) | Lapis and gold echo manuscript illumination (heritage, scholarship) without cliché; strong AA contrast; cyan was overloaded with meanings | Moving away from the current look means every screen must be restyled |
| D6 | Type: Source Serif 4 (titles), IBM Plex Sans (UI), IBM Plex Mono (timer and codes) | Inter-only; a geometric display sans | The serif gives the "exam paper" identity; Plex has excellent tabular figures and an institutional tone; all OFL and self-hostable | Three families: strict role rules keep it at most two per screen |
| D7 | Dedicated exam layout without the app navigation | Keep AppShell during exams | Focus, fewer accidental exits, better keyboard order, mobile space | Candidates need an explicit "Leave exam" path (the receipt or an "Exit" button with confirmation) |
| D8 | No Urdu UI translation in this phase; the brand only | Full RTL localisation now | Scope and the competition deadline; logical CSS properties keep the door open | English-only interface text |
| D9 | Keep 5.3 semantics: local changes never count after the server deadline | Accept device-timestamped answers after reconnect | Device clocks are untrustworthy; the problem statement forbids unfair time gains | A candidate offline at the deadline can lose unsynced answers; the UI states this clearly |
| D10 | Audit performed read-only except for 5 gap fixes verified and pushed **before** the audit started (`d6f81f3`), at your explicit choice | Leave them uncommitted, or stash them | They close real problem-statement gaps (3.1, 3.6, 3.8, 4.6) and the competition cutoff is 20:00 PKT | The audit baseline is `d6f81f3`, not `d956666` |
| D11 | Phase 0 (deployment) placed before all redesign work | Start the redesign immediately | The rulebook requires a deployed, working app; no commits or deploys after 20:00 PKT | The redesign is a post-competition programme unless explicitly fast-tracked |
